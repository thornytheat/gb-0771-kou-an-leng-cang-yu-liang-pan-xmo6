# 冷库数据定义

- CSV 为 UTF-8，首列可带 BOM，表头字符串严格识别。原始物理行在 `line` 和 `raw` 留证。空行及重复表头单列。同事件号按货批、动作、槽位、查验单、生效秒对比，一致时取最早收件，矛盾组整体隔离。`-`、`N/A`、`NULL`、`未知`、空串均视作缺值。
- `window` 是 `from`、`until` 两个带偏移时刻，窗口 `[from,until)`。系统统一为 UTC 秒，收盘容量取结束前一秒。`lots` 含字符串 `lot`、正整数 `pieces`、`description`。
- `slots` 含 `slot,revision,door,capacity,from,until`。槽位随半开有效期选版，同刻多版保留冲突证据。容量以件表示，货批整体调位。
- `moves` 含 `event,lot,kind,slot,ticket,effective,received`，另可带可选的 `pieces` 列（别名 `quantity`、`qty`）。收件用于迟到标记，生效顺序决定状态。同货批同时发生两条改变状态的动作时隔离。不同货批同秒按货批号稳定处理。`IN` 入库，`MOVE` 调位，`OUT` 出库，`HOLD` 冻结，`RELEASE` 或 `CANCEL` 解除指定冻结，`SEAL` 核对查验单。调位携带冻结，撤销保留最后实际槽位。调入超容时保留原槽位。缺槽位证据时保留申报槽位，计入待查。迟到后完整复算，接收时刻须不早于生效时刻。
- 拆批：`OUT` 带 `pieces` 或 `kind=SPLIT` 时按实走件数结清余量。实走件须少于余件且为 `OUT`/`SPLIT` 独有；余件留在原槽位、保持原查验单并继续占位。件数超余件记 `SPLIT_EXCEEDED`，非出库动作带件数或拆批缺件数记 `SPLIT_INVALID`。整批 `OUT` 不清 `pieces`。同号拆批单件数不同时整组隔离，重跑同一张单只扣一次。生效时刻决定落账与暴露切分，迟到的拆批单仍按生效时刻复算。
- `doors` 含 `door,signal,effective`。信号为 `OPEN`、`CLOSED`，短于 30 秒并恢复先前状态的脉冲算抖动。同刻门态冲突使该段待证。`temperatures` 含 `door,celsius,effective`。摄氏按 Decimal 比较，读数支持三位小数、范围 -90 至 80。用 `[采样时刻,采样时刻+600秒)`，新读数覆盖旧读数。开门且温度严格大于 4°C 判超限。
- 每货批在库秒按槽位版本、门态和温度边缘切片，分类顺序为缺槽位、缺门态、闭门、缺温、超限或合格。货批分钟由秒除以 60，未乘货批件数。库存项以件计。容量缩减造成的超容显示差额，容量 + 超容 = 普通占用 + 冻结 + 空余。拆批货批的在库秒仍按货批整体计一次，拆批前后时段由生效时刻切开、首尾相接；拆批台账另按实走件归属 `[上次件数变更, 本次生效)` 的暴露秒，某秒只归一处，重复认领计入 `duplicated`，未覆盖计入 `unattributed`。
- 件数勾稽：入库件数 - 拆批结清件数 - 整批出库件数 = 收盘在库余件。归档摘要与证据导出同时保留拆批台账（实走件、余件、原槽位、申报去向、查验单、归实走件的暴露秒与迟到标记）。
- 原件和结果摘要为 SHA-256。归档地址由原件摘要和规则版本决定。归档事务一次持久化，复跑比较结果摘要。证据导出包含槽位、动作、门态、温度的原始行号和分类差额。
